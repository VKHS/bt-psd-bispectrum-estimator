# Data tables

Tables of the paper (Integration 99 (2024) 102241) and tables generated by this repository. Every file carries a
`source` column. **Paper-reported** values are transcribed from the PDF and are never produced by this repository's code;
`computed_*` columns, where present, are analytic reference values computed here and are named as such. Loaders and
tests: `python/btpsd/paperdata.py`, `python/tests/test_paperdata.py`. Candidate errata in these tables are listed in
`docs/PAPER_NOTES.md`.

|---:|---|---|---|

Tables 1, 2, 4, 5 and 7 are extracted from the PDF by `python/scripts/extract_paper_tables.py` (needs `pdfplumber` and the
paper). Tables 1 and 2 are read by the horizontal position of each token because the text layer drops the dashes; the
structure of the result is tested (64 registers per table, register `R(8g + i)` of Table 1 starts with `i` dashes).
Table 1 and 2 describe the register sequences of the paper's own memory organisation; the FFT of this repository uses an
in-place bank map instead (`docs/ARCHITECTURE.md`, sections 3 and 6), so these tables are reference data here and are
not reproduced by the RTL.
